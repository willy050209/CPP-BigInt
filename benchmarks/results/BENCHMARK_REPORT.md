# Cross-Language & Cross-Library BigInt Benchmark Report

本報告詳細記錄 **CPP-BigInt (`numeric::bigint`)** 與產業界主流高精度整數庫的綜合效能對比。

- **評測環境**: Windows 11 x64, MSVC 2022 / v145, .NET 10.0, Python 3.12.10

- **參與評測庫**: CPP-BigInt, C++ GMP (MPIR), .NET 10, Python 3.12 (int), Python (gmpy2/GMP)


---

## 核心結論摘要 (Executive Summary)

1. **128-bit Small Buffer Optimization (SBO) 優勢顯著**：

   - 在 **64-bit 與 128-bit** 區間內，`CPP-BigInt` 達成 **0 Heap Allocation**，加法延遲僅 **~28.5 ns/op**，乘法僅 **~14.8 ns/op**。

   - 相較於 C++ GMP（每次運算皆經由 `malloc` 配置），`CPP-BigInt` 在小位數四則運算上展現高達 **4x ~ 8x 的加速比**。

   - 相較於 .NET 10 `BigInteger`，`CPP-BigInt` 在小位數乘法上快達 **28x**，加法快 **9.4x**。

2. **記憶體配置壓力測試 (Allocation Pressure)**：

   - 緊密迴圈高頻產生右值臨時變數時，`CPP-BigInt` 憑藉 SBO 在 64-bit 延遲僅 **69.7 ns/op**；對比 .NET GC (450 ns) 與 Python (215 ns) 具備極強延遲優勢。

3. **中大位數與 Karatsuba 乘法表現**：

   - 在 512-bit ~ 1024-bit 區間，`CPP-BigInt` 的 Karatsuba 乘法與長除法達到工業級水準，與 GNU MP 互有勝負。

   - 當位數擴展至 10,000 ~ 65,536 bits 時，GNU MP 啟動 Toom-Cook 3/4 與 FFT (Schönhage–Strassen) 展現亞二次方頂級效能；而 `CPP-BigInt` 依然在 65,536 bits 乘法跑出 1.7 ms 的穩定表現。
