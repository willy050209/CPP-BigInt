# Cross-Language & Cross-Library BigInt Benchmark Report

本報告詳細記錄 **CPP-BigInt (`numeric::bigint`)** 與產業界主流高精度整數庫的綜合效能對比。

- **評測環境**: Windows 11 x64, MSVC 2022 / v145, .NET 10.0, Python 3.12.10

- **參與評測庫**: CPP-BigInt, C++ GMP (MPIR), .NET 10, Python 3.12 (int), Python (gmpy2/GMP)


---

## 核心結論摘要 (Executive Summary)

1. **256-bit Small Buffer Optimization (SBO) 與零拷貝優勢顯著**：
   - 在 **64-bit 至 256-bit** 區間內，`CPP-BigInt` 達成 **0 Heap Allocation**，Direct-Result 運算子使 64-bit 加法延遲僅 **~9.4 ns/op**，乘法僅 **~7.0 ns/op**。
   - 小規模 `ToString_10` 改用棧上逆向格式化與 2-digit LUT 查表，64-bit 格式化開銷 **0 Heap**，延遲降至 **~20.4 ns/op**，超越 MPIR 達 **3.27x**。
   - 相較於 C++ GMP/MPIR（每次運算皆經由 `malloc` 配置），`CPP-BigInt` 在小位數四則運算上展現卓越的零配置延遲優勢。

2. **記憶體配置壓力測試 (Allocation Pressure)**：
   - 緊密迴圈高頻產生右值臨時變數時，`CPP-BigInt` 憑藉 256-bit SBO 在 64-bit 延遲僅 **~63.5 ns/op**；對比受 GC 或直譯開銷影響之環境具備極強延遲優勢。

3. **中大位數乘除法與進位轉換重大突破 (Burnikel-Ziegler Dispatch)**：
   - 修正並啟用 **Burnikel-Ziegler $D_{2n,n} / D_{3n,2n}$ 分治長除法** 後，65,536-bit 除法延遲由 306.45 $\mu$s 劇降至 **118.22 $\mu$s**（**2.59x 加速**），取模降至 **116.89 $\mu$s**（**2.30x 加速**，超越 MPIR 3.65x）。
   - 受惠於 BZ 快速除法，65,536-bit `ToString_10` 延遲由 708.82 $\mu$s 降至 **433.02 $\mu$s**（**1.64x 加速**，超越 MPIR 2.49x、.NET 10 達 11.83x）。
   - 引入線程局部 RAII `ScratchArena`，大數 Karatsuba 乘法與 BZ 遞迴除法在深度內達成 **0 次 Heap 動態配置**。
